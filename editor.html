Cómo publicar los cambios

  1. Haz tus cambios aquí. Se guardan solos en este navegador.
  2. Presiona Descargar equipos.json.
  3. En GitHub: Add file → Upload files, arrastra el archivo descargado (y el plano nuevo, si cambiaste uno) y presiona Commit changes.
  4. En 1 o 2 minutos todos ven la app actualizada.

Si Windows guarda el archivo como «equipos (1).json», renómbralo a equipos.json antes de subirlo.
